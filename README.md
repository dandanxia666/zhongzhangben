# 众账本（Zhong Zhang Ben）

面向社团、学生组织、合伙小团队的**经费透明账本系统**。把《小企业会计准则》的复式记账规范简化成直观操作流，兼顾财务严谨性与公开透明度。

## 核心特性

- **借贷平衡硬性校验**：每笔凭证借贷必须严格相等（精确到分），不平则拦截保存。
- **双人制约，未审不入账**：制单与复核分离，待复核凭证不计入账簿与报表。
- **零物理删除，红冲更正**：已生效凭证不可修改删除，只能通过红冲凭证冲销更正，保留完整审计链。
- **月度三步锁账与自动结转**：结账前校验待复核凭证、借贷平衡、会计恒等式，通过后自动结转损益并封账。
- **无门槛公开监督**：生成带随机密钥的只读链接，任何人免登录即可查看收支与流水。

角色分为管理员（制单/复核/结账/成员管理）、只读成员（查账）、访客（公开监督链接）。

## 技术栈

- 后端：Node.js 内置模块（零第三方依赖），`server.js` 提供静态服务、登录鉴权、业务 API、SSE 实时同步、原子化 JSON 持久化。
- 前端：原生 HTML/JS 单页应用（`code.html`），会计引擎 `engine.js` 前后端共用，规则由服务端强制。

## 本地运行

```bash
node server.js
```

默认监听 `8100` 端口，可通过环境变量 `PORT` 覆盖。浏览器打开 `http://localhost:8100`。

首次启动会自动生成种子数据：`zzb-data.json`（账本）、`users.json`（口令散列）。内置演示账号默认口令为 `123456`。

> 注意：`users.json` 与 `zzb-data.json` 属于运行时数据，已加入 `.gitignore`，不会提交到仓库。部署到线上时请自行保管并设置强口令。
